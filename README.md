# Анализ эффективности рекламных кампаний

## Задача
Проанализировать данные о рекламных кампаниях и найти наиболее эффективные комбинации "Платформа + Тип контента" для оптимизации рекламного бюджета

## Этапы работы и инструменты
1. **PostgreSQL (pgAdmin):** Данные загружены в базу, написаны запросы для расчетов CPC и Conversion Rate и поиска компаний с максимальным CTR на каждой платформе с помощью оконных функций (`RANK()`).
2. **Python (Pandas, Google Colab):** Проведена очистка данных (проверка типов, обработка пропусков). Рассчитана новая метрика **CPA (Cost Per Acquisition)** с защитой от деления на ноль. Очищенный датасет сохранен.
3. **Power BI:** Построен интерактивный дашборд с карточками KPI, тепловой картой конверсий и гистограммами по CPA и ROI. Настроила фильтры (слайсеры) для анализа по типам контента.

## Главные выводы 
*   **Facebook** - лидер по дешевизне привлечения клиента (самый низкий средний CPA), при этом высокая окупаемость инвестиций. Баннеры - идеальный вариант для платформы (CPA ниже среднего, ROI выше среднего). Отлично подходит для товаров среднего ценового сегмента.
*   **Twitter + посты** - связка-лидер по окупаемости инвестиций (самый высокий средний ROI). Однако стоимость привлечения там выше, что делает его подходящим для премиум-товаров и больших бюджетов.
*   **Видео** - самый дорогой вид рекламного контента.
*   **Лучшие связки:** - Twitter + карусели/баннеры (низкая стоимость привлечения, при этом хорошая окупаемость).
*   **LinkedIn** - показывает высокий CPA и низкий ROI почти везде, кроме связки с баннерами, что делает его неэффективным для данной стратегии. 

## Структура проекта 
*   `queries.sql` - SQL-запросы (агрегация, оконные функции).
*   `pandas_data_cleaning.ipynb` - ноутбук с очисткой данных и расчетом метрики CPA.
*   `acp_clean.csv` - очищенный датасет для визуализации.
*   `dashboard/` - файлы дашборда Power BI (`.pbix`), скриншоты и PDF-версия.
*   `advertising_campaign_performance.csv` - исходные данные.
